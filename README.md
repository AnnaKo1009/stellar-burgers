# Проектная работа Stellar Burger 
Stellar Burger — это одностраничное веб-приложение для создания и заказа персонализированных бургеров, разработанное с использованием современных технологий фронтенд-разработки.

Основные функции приложения:

Создание собственных бургеров из различных ингредиентов;
Система авторизации пользователей;
Личный кабинет с историей заказов;
Управление заказами в режиме реального времени;
Защищённые маршруты для персональных данных;

Ключевые технологии:

React — для построения пользовательского интерфейса;
TypeScript — для строгой типизации кода;
Redux — для управления глобальным состоянием;
React Router — для реализации маршрутизации;
Jest и Cypress — для тестирования;

## Этапы работы:

1. Разверните проект и ознакомьтесь с кодом. Все необходимые вам компоненты уже созданы и лежат в папке `src/components`

2. Настройте роутинг.

3. Напишите функционал запросов данных с сервера, используя `Redux` и глобальный `store`. Сами "ручки" уже прописаны и лежат в `utils/burger-api.ts`

4. Настройте авторизацию и создайте защищённые роуты.

## Важно:

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.
